## Things I've built

### [Email Checker](https://github.com/CamPadMos/email-checker) · [try it here](https://campadmos.github.io/email-checker)

Gmail and Outlook still let some phishing through, so I built a tool that checks an email and explains, in plain words, why it looks suspicious: failed SPF/DKIM/DMARC checks, look-alike domains, links that show one site and open another. Everything runs in your browser, so the email never leaves your device. You can also connect your Gmail and have new messages scanned and labeled automatically.

### [HoopXpots security audit](https://github.com/CamPadMos/hoopxpots-security-audit)

HoopXpots is a site I built to help people in Houston find courts and pickup games. I audited it the same way an analyst would audit someone else's app, and found 11 issues. The worst one: my database rules let anyone read every user's email address. I fixed 9, documented why the other 2 stay, and shut off 23 Google APIs I wasn't even using. The repo has the full report and my rules before and after.
